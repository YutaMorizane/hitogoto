# ストーリー生成プラン

## 概要

要件定義書（FR-001〜FR-013）と原案のユーザーストーリー案に基づき、Phase 1スコープのユーザーストーリーを生成する。

## ストーリー分解アプローチ

**採用方式**: ペルソナベース × ユーザージャーニーのハイブリッド

- 3つのユーザーロール（主催者/承認者/オブザーバ）ごとにストーリーをグループ化する
- 各ロール内では会議のライフサイクル（準備→会議中→会議後）に沿って整理する
- 横断的な機能（認証、ダメ人間度メーター）は共通ストーリーとして独立させる

## 生成ステップ

- [x] Step 1: ペルソナ定義（3ロール + 共通属性）
- [x] Step 2: 主催者ストーリー生成（会議準備→会議中→会議後）
- [x] Step 3: 承認者ストーリー生成（会議中→会議後）
- [x] Step 4: オブザーバストーリー生成（会議中→会議後）
- [x] Step 5: 共通ストーリー生成（認証、ダメ人間度メーター、接続管理）
- [x] Step 6: 受け入れ基準の付与（全ストーリー）
- [x] Step 7: INVEST基準の検証
- [x] Step 8: ペルソナ↔ストーリーのマッピング
