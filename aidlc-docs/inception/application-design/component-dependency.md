## 通信パターン

| 通信経路 | パターン | プロトコル | 用途 |
| --- | --- | --- | --- |
| フロントエンド → バックエンド（CRUD） | 同期リクエスト/レスポンス | REST API（HTTPS） | 会議セッション管理、認証、設定、履歴取得 |
| フロントエンド → バックエンド（AI生成リクエスト） | 同期リクエスト | REST API（HTTPS） | 代弁案生成リクエスト送信 |
| バックエンド → フロントエンド（AI応答） | 非同期プッシュ（ストリーミング） | WebSocket | 代弁案のストリーミング配信 |
| バックエンド → フロントエンド（リカバリー案） | 非同期プッシュ | WebSocket | 即時リカバリー案の配信 |
| バックエンド → フロントエンド（モード推奨） | 非同期プッシュ | WebSocket | モード推奨の配信 |
| フロントエンド → Transcribe | ストリーミング | WebSocket（直接接続） | 音声データの送信・文字起こし結果の受信 |

## データフロー

### AI代弁フロー（ハイブリッド通信）

```
ユーザー入力 → [REST API] → Lambda(代弁サービス)
                                    ↓
                            プロンプト構築(C-AI-001)
                                    ↓
                            Bedrock呼び出し(C-AI-002)
                                    ↓ (ストリーミング)
                            [WebSocket] → フロントエンド表示
                                    ↓ (承認後)
                            発言履歴保存(C-DATA-003)
                            ダメ人間度更新(C-DATA-004)
```

### 音声文字起こしフロー（クライアント直接接続）

```
マイク/システム音声 → [C-FE-008] → [WebSocket直接] → Transcribe Streaming
                                                            ↓
                                                    文字起こし結果
                                                            ↓
                                            [C-FE-010] 状態管理に保存
                                                            ↓
                                            [WebSocket] → バックエンド（文脈更新）
```
