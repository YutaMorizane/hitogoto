# コンポーネント定義

## 設計制約

- 全UIコンポーネントはSerendie Design Systemに準拠する。ボタン、フォーム、カード、モーダル等の基本UIパーツはSerendie DSのコンポーネントを使用し、独自スタイルの作成は最小限に留める。

## UOW-1: フロントエンド コンポーネント

### C-FE-001: ページルーター

- **目的**: マルチページ構成のルーティング管理
- **責務**:
  - ページ遷移の制御（ダッシュボード/会議/設定/履歴）
  - 認証状態に基づくアクセス制御（未認証→ログイン画面へリダイレクト）
  - URLパラメータの管理

### C-FE-002: 認証UI

- **目的**: ユーザー認証に関するUI提供
- **責務**:
  - サインアップフォーム表示・バリデーション
  - ログインフォーム表示・バリデーション
  - パスワードリセットフロー
  - Cognito SDKとの連携

### C-FE-003: ダッシュボード画面

- **目的**: ユーザーのホーム画面。会議履歴・ダメ人間度・クイックアクションを表示
- **責務**:
  - ダメ人間度メーターの表示（累積レベル、推移グラフ）
  - 直近の会議履歴一覧表示
  - 新規会議セッション開始ボタン
  - 責任引き受け履歴の表示

### C-FE-004: 会議画面（メイン）

- **目的**: 会議中のリアルタイム操作を提供するメイン画面
- **責務**:
  - HUD形式のオーバーレイ表示
  - AI代弁入力エリア（テキスト入力 + 音声ウィスパー + 定型文ボタン）
  - 代弁案表示・承認・却下・編集UI
  - モード切替UI（代弁/フォロー/言い換え/しらんけど + 自動推奨表示）
  - リアルタイム文字起こし表示
  - 接続状態表示
  - 宛先（発言対象者）選択UI
  - 自動承認モードON/OFF切替
- **実装時のサブコンポーネント分割方針**:
  - HUDオーバーレイ（表示/非表示制御）
  - 入力パネル（テキスト/ウィスパー/定型文）
  - 代弁案カード（表示/編集/承認/却下）
  - モードセレクター（切替UI + 推奨表示）
  - 文字起こしパネル（リアルタイム表示）
  - ステータスバー（接続状態/自動承認/宛先）

### C-FE-005: 会議後画面

- **目的**: 会議終了後のサマリ・ダメ人間度演出を表示
- **責務**:
  - 会議サマリ（要点・決定事項・未解決事項・次アクション）表示
  - ダメ人間度+N演出表示
  - サマリ編集・保存
  - 意思決定ログ表示

### C-FE-006: 設定画面

- **目的**: ユーザー設定・同意管理を提供
- **責務**:
  - デフォルトモード設定
  - 自動承認モードのデフォルト設定
  - 会議データ共有範囲設定
  - 会議データ保存期間設定
  - 定型文カスタマイズ

### C-FE-007: 履歴画面

- **目的**: 過去の会議履歴とサマリの閲覧
- **責務**:
  - 会議一覧表示（日付、参加者、ダメ人間度）
  - 会議サマリ詳細表示
  - 責任帰属変更履歴の閲覧

### C-FE-008: 音声キャプチャモジュール

- **目的**: ブラウザの音声取得を管理
- **責務**:
  - マイク入力の取得（MediaDevices API）
  - システム音声の取得（Screen Capture API / getDisplayMedia）
  - 音声ストリームのTranscribe Streamingへの直接送信
  - ウィスパー入力の分離処理

### C-FE-009: WebSocket接続モジュール

- **目的**: バックエンドとのリアルタイム通信を管理
- **責務**:
  - WebSocket接続の確立・維持
  - 自動再接続処理
  - 接続状態の管理・通知
  - AI応答のストリーミング受信

### C-FE-010: 状態管理ストア（Zustand）

- **目的**: アプリケーション全体の状態を一元管理
- **責務**:
  - 会議セッション状態（参加者、モード、接続状態）
  - AI代弁案の状態（生成中/表示中/承認済み）
  - ダメ人間度の状態
  - 文字起こし結果の状態
  - 自動承認モードの状態

## UOW-2: AI処理 コンポーネント

### C-AI-001: プロンプトマネージャー

- **目的**: AI生成のプロンプトを管理・構築
- **責務**:
  - ベースプロンプトの管理
  - モード別パラメータの注入（代弁/フォロー/言い換え/しらんけど）
  - 参加者プロファイルのコンテキスト注入
  - 会議文脈（直前の発言）のコンテキスト注入
  - 宛先に応じたトーン調整指示の生成

### C-AI-002: 代弁案ジェネレーター

- **目的**: AI代弁案を生成
- **責務**:
  - Bedrock API（Claude）の呼び出し
  - ストリーミングレスポンスの処理
  - 生成結果のフォーマット
  - レイテンシ管理（5秒以内）

### C-AI-003: リカバリー案ジェネレーター

- **目的**: 即時リカバリー案を生成
- **責務**:
  - 相手の反応（反論・困惑）の分析
  - リカバリー案（言い換え/撤回/補足）の生成
  - レイテンシ管理（3秒以内）

### C-AI-004: サマリジェネレーター

- **目的**: 会議終了後のサマリ・意思決定ログ・次アクションを生成
- **責務**:
  - 会議全体の文字起こしデータからサマリ生成
  - 意思決定ログの抽出
  - 次アクション（TODO）の抽出
  - 未解決事項の識別

### C-AI-005: モード推奨エンジン

- **目的**: 会議の文脈に応じて最適なモードを推奨
- **責務**:
  - 会議の文脈分析（相手の発言トーン、議題の種類）
  - 推奨モードの判定
  - 推奨理由の生成

## UOW-3: データ・セッション管理 コンポーネント

### C-DATA-001: ユーザー管理

- **目的**: ユーザーアカウントの管理
- **責務**:
  - Cognito連携（認証・認可）
  - ユーザープロファイルの管理
  - セッショントークンの検証

### C-DATA-002: 会議セッション管理

- **目的**: 会議セッションのライフサイクル管理
- **責務**:
  - セッションの作成・終了
  - 参加者プロファイルの保存・取得
  - 会議履歴の保存・検索
  - 会議データの共有範囲・保存期間管理

### C-DATA-003: 発言履歴管理

- **目的**: AI代弁・フォロー・リカバリーの発言履歴を管理
- **責務**:
  - 発言内容の保存（代弁案、承認状態、責任帰属）
  - 責任帰属変更の記録
  - 訂正履歴の管理
  - 発言対象者（宛先）の記録

### C-DATA-004: ダメ人間度管理

- **目的**: ダメ人間度の算出・保存・取得
- **責務**:
  - AI代弁利用回数のカウント
  - AI任せ割合の算出
  - ダメ人間度レベルの算出
  - 累積データの保存・推移管理
  - 責任引き受け履歴の管理

### C-DATA-005: 同意管理

- **目的**: 透明性・同意に関するデータ管理
- **責務**:
  - 参加者の同意状態の記録
  - 録音・文字起こし通知の記録
  - データ共有範囲・保存期間の設定管理

## UOW-4: インフラ + リアルタイム基盤 コンポーネント

### C-INFRA-001: CDKスタック

- **目的**: AWSリソースの定義・デプロイ
- **責務**:
  - Lambda関数の定義
  - API Gateway（REST + WebSocket）の定義
  - DynamoDBテーブルの定義
  - Cognito User Poolの定義
  - S3バケットの定義
  - CloudFrontディストリビューションの定義
  - IAMロール・ポリシーの定義

### C-INFRA-002: WebSocket接続マネージャー

- **目的**: WebSocket接続のサーバー側管理
- **責務**:
  - 接続の確立（$connect）
  - 切断処理（$disconnect）
  - 接続IDの管理（DynamoDB）
  - メッセージルーティング
  - AI応答のプッシュ配信

### C-INFRA-003: 音声処理ブリッジ

- **目的**: Transcribe Streaming接続のための一時認証情報提供
- **責務**:
  - STS一時認証情報の発行（Transcribe Streaming用）
  - 認証情報のローテーション管理
  - 音声処理の設定管理（言語、サンプリングレート等）

### C-INFRA-004: CI/CDパイプライン

- **目的**: 自動ビルド・デプロイの管理
- **責務**:
  - ソースコードのビルド
  - テスト実行
  - CDKデプロイ
  - フロントエンドのS3デプロイ + CloudFrontキャッシュ無効化
